# 目标编辑与测试会话（v0.4 设计）

状态：已与产品确认，分阶段实现中。本文是唯一口径；实现偏离时必须先改这里。

## 1. 产品模型

画布两段式：

1. **目标编辑**：在画布上查看、增删改、拖拽目标体系，备注在右侧详情面板编辑。
2. **回忆工作台**：新建「测试临时工作区」，闭卷从零搭建，提交后自动对比并写回掌握状态。

「画上即掌握」不再是默认语义；掌握状态由测试会话写入。

## 2. 会话

| 项 | 规则 |
|---|---|
| 入口 | 目标工作区顶栏「开始测试」；⌘K 同名命令 |
| 模式 | 会话开始二选一：**测试**（闭卷，结果计入）／**练习**（开卷，不计入）；默认测试 |
| 闭卷 | 隐藏目标面板、幽灵、置信度 |
| 工作区 | 临时工作区附属当前工作区，不进切换列表，带 **目标快照**（会话期间目标冻结） |
| 起点 | 尝试图空白，根节点预填目标根标题 |
| 提交 | 点「提交测试」→ 尝试图只读 → 自动对比 → 写回；失败仍锁定，只能重试或重测 |
| 结束 | 三选一：替换原图 / 合并 / 丢弃 |
| 费用 | 提交前显示 token 预估，>20k 二次确认 |

## 3. 掌握状态

```
未学 --(目标节点进入我的图)--> 学习中 --(闭卷测试匹配)--> 已掌握
                                   ^                      |
                                   +----(下次测试失败)-----+
```

- 匹配上 → 已掌握，记录置信度、会话 id、时间；练习永不写入。
- 未匹配但原工作区图中有同名节点（NFKC 归一化）→ 学习中。
- 都没有 → 未学（不写记录）。
- 同一目标以最近一次测试为准；保留最近 10 次会话，暂不做趋势图。
- 不允许手动改判；置信度只展示、不参与判定。

## 4. 目标大纲 / 画布上的标记

每个目标节点：

- 掌握状态圆点：未学 / 学习中 / 已掌握（目标树行）。
- 目标画布节点按状态着色：已掌握=蓝色描边 + 浅蓝底，学习中=琥珀描边 + 浅琥珀底，未学=中性描边；悬停显示置信度。
- 置信度：仅已掌握显示（10px mono，<70% 弱化）。
- 详情面板：状态、置信度、来源（第 N 次测试 / 尚无测试）、测试时间、判定依据（匹配到的画布节点标题）。

树上不显示备注、自测问题、参考链接。

边界：

- 从未测试：全部未学，置信度「—」。
- 测试后改目标：同 id 保留，新增=未学，删除即删，重命名/移动保留；提示「目标已修改，上次测试早于修改」。
- 大纲批量导入生成新 id → 结果重置，提交前提示。

## 6. 分阶段

1. **已完成**：目标画布编辑（结构增删改/拖拽、独立撤销栈、自动保存、右侧备注编辑；大纲弹窗仅保留批量导入）。
2. **已完成**：会话——临时工作区（`Workspace.session`，不进切换列表）、闭卷/练习、提交锁定、预估与 20k 二次确认、结果弹窗（替换/合并/丢弃）。
3. **已完成**：投影——目标树状态点与置信度、详情面板来源与时间、目标被改后的过期提示、最近 10 次会话存档、**目标画布节点按状态着色**（已掌握=蓝、学习中=琥珀、未学=中性）。
4. **未做**：会话历史列表界面（数据已存档）；多目标并排；画布角标数字（置信度在悬停提示里）。

## 6.1 实现说明

- 会话存在 `workspace.session`，尝试图即 `session.attempt`；会话期间 `App` 把 `workspaceStore.activeMap` 交给画布，编辑写入 `updateAttempt()`，原图不动。
- 提交前调用 `lockSession()` 冻结尝试图；模型调用失败保持锁定并提供「重试对比」。
- `computeMastery()` 是纯函数：匹配上 → 已掌握（带置信度）；未匹配但在尝试图或原图里 → 学习中；都没有 → 未学（不写记录）；目标根节点不计入。
- 目标被修改后，详情面板提示「目标已修改，上次测试早于修改」（比较 `target.updatedAt` 与最近一次判定时间）。
- 练习模式永不写入掌握状态；提交也不会调用 `computeMastery`。

## 7. 交互约定（目标画布）

- 左键拖空白平移；左键拖节点改父子；右键拖框选；`Space+左键` 平移（与主画布一致）。
- `Tab` 子节点、`Enter` 同级、`F2` 重命名、`Delete` 删除、`Ctrl/⌘+Z` 撤销。
- 编辑目标后旧对比标记过期（沿用 `ui.markStale`）。
